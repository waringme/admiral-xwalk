# Features

A list of feature items, each with optional icon or photo and a heading with supporting copy.

| Feature | |
| --- | --- |
| Icon or photo (optional) | Image and alt text |
| Text | Heading (heading 3) and supporting text |

- Add a **Feature** item for each entry. Use an optional image for an icon or illustration and provide alt text when it conveys information.
- Styles: **Alternating (icon left / right)**, **Rows with photo and arrow**, **Ticked list**, **Numbered steps**, or **Icon columns (three across)**.
- In the rows style, a link in the heading marks the item as linked. Use a descriptive heading link.
- Authored content is retained and arranged into the feature list; row markers are preserved for Universal Editor selection.

`features.js`, `features.css`, `_features.json`
