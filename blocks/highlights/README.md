# Highlights

A group of short benefit pods with optional icons, headings and supporting text.

| Highlight | |
| --- | --- |
| Icon (optional) | Icon image and alt text |
| Text | Heading (heading 3) and copy |

- Add one **Highlight** item for each benefit. An optional icon is shown with the text.
- Choose **Admiral blue** for the default appearance or **Pink / yellow / orange** for the alternating colour treatment.
- Use concise headings and copy that remain understandable when read independently.

## Accessibility

Provide alt text for informative icons. If an icon is decorative or repeats the text, use empty alt text.

`highlights.js`, `highlights.css`, `_highlights.json`
