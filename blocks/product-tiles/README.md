# Product Tiles

A grid of linked product shortcuts with a product icon and label.

| Product Tile | |
| --- | --- |
| Icon | Select a product icon |
| Link | Destination |
| Label | Visible link text |

- Add a **Product Tile** for each product. Select the appropriate icon, choose its destination and enter a concise **Label**.
- The entire tile is one link; the icon is decorative and hidden from assistive technology.
- Rows without a link are omitted from the rendered grid.

## Accessibility

Use a label that makes the destination clear without relying on the icon.

`product-tiles.js`, `product-tiles.css`, `_product-tiles.json`
