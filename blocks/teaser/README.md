# Teaser

A compact promotional banner with an image strip and a copy panel. It can be used for promotional content, an app download prompt or a finder banner.

| Teaser | |
| --- | --- |
| Image | Desktop image |
| Mobile Image (optional) | Mobile image |
| Text | Heading, paragraph(s) and CTA or store links |

- Add a desktop image and optionally a mobile-specific image. If no mobile image is provided, the desktop image is used.
- Use **Text** for the heading, supporting copy and optional CTA.
- Styles: **Light** gives the copy panel a pale-blue background; **Image after copy (mobile)** places the image after the copy on mobile; **App store badges** styles a paragraph containing Apple App Store and Google Play links as store badges.
- For the app style, put both store links in the same paragraph and use their normal destination URLs. Their link text remains available to screen readers.

## Accessibility

Provide suitable alt text for informative images and meaningful names for CTA/store links.
