# Banner

An award or recognition band with artwork beside a heading and supporting copy on a dark-blue background.

| Banner | |
| --- | --- |
| Image | Desktop award artwork |
| Mobile Image (optional) | Mobile artwork |
| Text | Heading and supporting paragraph |

- Select the desktop artwork and provide meaningful **Image Alt** text where the image conveys information.
- Optionally select **Mobile Image** and **Mobile Image Alt** for a separate narrow-screen asset. Without a mobile image, the desktop image is used.
- Use **Text** for the heading and strapline. Shift+Enter line breaks are retained.
- The layout stacks on small screens and places the image beside the copy on wider screens.

## Accessibility

Images retain their authored alt text. Keep the heading hierarchy appropriate to the page.
