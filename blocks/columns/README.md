# Columns

The standard Edge Delivery columns block for laying out content side by side.

| Columns | |
| --- | --- |
| Columns | Number of columns |
| Rows | Number of rows |
| Column | Text, image, button or title components |

- Set the column and row counts, then add content to each column using the Universal Editor.
- A column containing only an image is marked for image-column styling.
- The block does not introduce custom interaction; responsive layout is controlled by its stylesheet and global styles.

`columns.js`, `columns.css`, `_columns.json`
