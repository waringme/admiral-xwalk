# Media Text

A panel combining an image with a heading and rich-text copy. On mobile the image follows the copy; the **Image on the right** option reverses the desktop order.

| Media Text | |
| --- | --- |
| Image | DAM image or character cut-out |
| Alt | Alternative text |
| Text | Heading, paragraphs and/or lists |

- Select a DAM asset in **Image** and provide **Alt** text when it communicates information.
- Add the heading and copy in **Text**. The block moves authored content into a copy area and places the image alongside it.
- Select **Image on the right** to position the media on the right on desktop. If the image is omitted, the text panel remains.
