# Callout

A compact notification or quote panel. The default style is yellow; the style selector also offers blue and white.

| Callout | |
| --- | --- |
| Text | Heading (for example, heading 3) and paragraph(s) |

- Write the heading and supporting copy in the rich-text **Text** field.
- Choose **Blue** for a pale-blue panel or **White (quote)** for the white quote-box treatment. Leave the colour unset for the yellow “Good to know” style.
- The authored contents are unwrapped in place; links and rich-text formatting are retained.

`callout.js`, `callout.css`, `_callout.json`
