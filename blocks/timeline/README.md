# Timeline

A chronological milestone timeline. Items alternate sides of the centre line on desktop.

| Milestone | |
| --- | --- |
| Icon or photo (optional) | Image and alt text |
| Image display | Icon (desktop only) or Feature (all screens) |
| Text | Date (heading 3), title (heading 2) and supporting text |

- Add one **Milestone** item per event and author its date, title and copy in the required heading order.
- Square images are treated as icons and appear above the date. Landscape images appear below the title as photos. Image placement uses the intrinsic dimensions where available.
- Choose **Feature (all screens)** when a square icon/graphic should also appear on mobile; **Icon (desktop only)** is the default. Landscape photos always show.
- The year of the first date is used as the timeline line's starting badge when the date contains a four-digit year.

## Accessibility

Provide useful alt text for images that add information; avoid placing event details only in the image.
